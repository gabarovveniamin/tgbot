# 📰 Telegram Suggestion Bot (Предложка)

Бот для предложки контента в Telegram-канал. Пользователи отправляют материалы через бота, администратор просматривает и публикует их в канале.

## ✨ Возможности

- **Все типы контента**: текст, фото, видео, GIF, стикеры, голосовые, видеосообщения, аудио, документы, альбомы (media group)
- **Анонимность**: пользователь выбирает — отправлять с подписью или анонимно
- **Панель администратора**: кнопки «Опубликовать», «Отклонить», «Ответить» под каждой предложкой
- **Автоматическая регистрация**: первый пользователь, написавший боту, становится администратором
- **Антиспам**: ограничение 5 предложек в минуту
- **Альбомы**: несколько фотографий/видео сохраняются как единая группа
- **Копирование контента**: сообщения не пересылаются (forward), а копируются — формат полностью сохраняется

## 🚀 Быстрый старт

### 1. Создание бота через BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Задайте имя и username бота.
4. Скопируйте токен (например: `7123456789:AAH...`).

### 2. Получение ID канала

**Способ 1 — через бота:**
1. Добавьте бота в канал как администратора (с правом отправлять сообщения).
2. Отправьте любое сообщение в канал.
3. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
4. Найдите поле `"chat": {"id": -100...}` — это и есть `CHANNEL_ID`.

**Способ 2 — через @userinfobot:**
1. Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot).
2. Бот покажет ID канала (формат `-100xxxxxxxxxx`).

> **Важно:** `CHANNEL_ID` — отрицательное число, начинающееся с `-100`.

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
CHANNEL_ID=-1001234567890
```

### 4. Запуск локально

```bash
# Клонирование / переход в папку
cd "tgc bot"

# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux / macOS)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

При первом запуске:
- Автоматически создастся файл `bot.db` (SQLite).
- Первый пользователь, отправивший `/start`, станет администратором.

### 5. Развёртывание на Render.com

1. **Залейте код на GitHub** (не забудьте `.gitignore` — `.env` и `.db` не попадут в репозиторий).

2. **Создайте сервис на Render:**
   - Перейдите на [render.com](https://render.com) → **New** → **Background Worker**.
   - Подключите GitHub-репозиторий.

3. **Настройте параметры:**
   | Поле              | Значение                      |
   |-------------------|-------------------------------|
   | Environment        | Python 3                      |
   | Build Command      | `pip install -r requirements.txt` |
   | Start Command      | `python main.py`              |

4. **Добавьте переменные окружения** в Render Dashboard → **Environment**:
   - `BOT_TOKEN` — токен бота
   - `CHANNEL_ID` — ID канала

5. Нажмите **Create Background Worker**. Бот запустится автоматически.

> **⚠️ Примечание:** Render использует эфемерную файловую систему. Файл `bot.db` будет
> удалён при каждом редеплое. Для продакшена с сохранением данных между деплоями
> рекомендуется использовать Render Disk или внешнюю БД.

```

│ id (PK)      │    │ id (PK)          │  │ id (PK)      │   │ id (PK)      │
│ telegram_id  │    │ telegram_id      │  │ user_id (FK) │──▶│ submission_id│
│ created_at   │    │ username         │  │ status       │   │ file_id      │
└──────────────┘    │ full_name        │  │ created_at   │   │ media_type   │
                    │ anonymous_mode   │  └──────────────┘   │ caption      │
                    │ created_at       │                      └──────────────┘
                    └──────────────────┘
```

**Статусы предложки:** `pending` → `published` | `rejected`
